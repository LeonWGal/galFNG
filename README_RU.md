# File Name Grabber

Простое приложение для быстрого получения списка имен файлов из папки.

## Описание

File Name Grabber - это удобное приложение, которое позволяет:
- Перетаскивать папку в окно приложения или выбирать её через диалог
- Получать список всех файлов в выбранной папке
- Выбирать разделитель между именами файлов (запятая, пробел или новая строка)
- Копировать полученный список в буфер обмена
- Поддерживает русский и английский языки интерфейса

## Требования

- Python 3.6 или выше
- PyQt6

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/LeonWGal/galFNG.git
cd galFNG
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python galFNG.py
```
