# File Name Grabber

A simple application for quickly getting a list of file names from a folder.

## Description

File Name Grabber is a convenient application that allows you to:
- Drag and drop a folder into the application window or select it through a dialog
- Get a list of all files in the selected folder
- Choose a separator between file names (comma, space, or new line)
- Copy the resulting list to clipboard
- Supports Russian and English interface languages

## Requirements

- Python 3.6 or higher
- PyQt6

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/namegrabber.git
cd namegrabber
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```
